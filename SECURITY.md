# Security

Threadmark stores local conversation excerpts and can inject retrieved text into Codex context. Its credential filtering is heuristic and retrieved text can be malicious or stale. See the [privacy and integration notes](docs/integration.md) before using it.

Please avoid posting credentials, private conversations, or an exploitable proof of concept in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use its Security tab to report a suspected vulnerability privately. If it is unavailable, contact the repository maintainers through a private channel before sharing sensitive details.
