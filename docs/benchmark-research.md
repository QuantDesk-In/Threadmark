# Benchmark interface research

Checked locally on 2026-10-29 using the installed first-party `codex-cli 0.165.0`; no model session, network request, user configuration, credentials, or historical chats were accessed. The primary evidence for the CLI statements below is the output of `codex --version` and `codex exec --help`, not a live end-to-end run. Interfaces can change by version.

- `codex exec` is a non-interactive interface. `--json` prints events to stdout as JSONL, `--model` selects a model, `--cd` selects the working root, and `--ephemeral` avoids persisting session files. The help does **not** specify event fields, completeness of usage accounting, or whether tool calls and cached-input tokens are observable. Treat unrecognized or absent metrics as unavailable, not zero; verify the event schema for the tested version before interpreting results.
- `--ignore-user-config` does not prevent the use of authentication from `CODEX_HOME`: the help explicitly says authentication still uses that location. A fresh temporary `CODEX_HOME` therefore has no assumed access to the user's authenticated account. Do not copy real credentials or silently fall back to the real home. A real experiment requires an explicitly authorized, isolated authentication/provider setup.
- `--dangerously-bypass-hook-trust` runs enabled hooks without persisted hook trust for that invocation. The help calls it dangerous and limits its intended use to automation that already vets hook sources. An experiment should use it only for explicitly authorized, reviewed synthetic hooks in an isolated environment; it is not evidence that normal interactive hook trust works.
- A clean, fresh session and equal prompts are necessary but not sufficient to establish causal effects. Preserve identical task state and settings, repeat pairs, measure both arms, and distinguish missing or failed runs from successful observations. Extra injected context may increase usage. Prompt caching is a different mechanism from Threadmark retrieval; neither cached input nor subscription limits can be inferred from character counts.
